# Verificação

node 09-verificacao/testar-controles.cjs
python3 09-verificacao/validar-kit.py

Python requer Pillow. O teste JS usa um DOM mínimo e valida comportamento, sem motor de renderização. O teste de arquivos verifica caminhos, anchors, JSON, alpha, SVG, integridade das fotografias e manifesto.

Antes de publicar: revisar Chrome, Safari e Firefox; larguras 390, 768 e 1440; zoom 200%; navegação por teclado; carregamento lento; falha de imagem e reduced motion. Confirmar contatos, condições de serviço e direitos de uso das fotografias. Não há site publicado nesta entrega.
